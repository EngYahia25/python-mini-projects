## 🗓️ Age & Days Calculator

> **Folder:** [`age-days-calculator/`](./age-days-calculator)

A simple calculator that converts your age in years into the approximate number of days you have lived. Features input validation and formatted output.

**Quick run:**
```bash
cd age-days-calculator
python main.py
```

---

## 🎲 Number Guessing Game

> **Folder:** [`number-guessing-game/`](./number-guessing-game)

Guess a randomly generated secret number between 1 and 10. The game gives you "too high" or "too low" hints and tracks how many attempts you needed.

**Quick run:**
```bash
cd number-guessing-game
python main.py
```

---

## 🍅 Pomodoro Timer

> **Folder:** [`pomodoro-timer/`](./pomodoro-timer)

A CLI implementation of the Pomodoro productivity technique. Set a work interval in minutes and watch the live countdown. An alert fires when your session ends.

**Quick run:**
```bash
cd pomodoro-timer
python main.py
```

---

## ✅ To-Do List

> **Folder:** [`todo-list/`](./todo-list)

An interactive menu-driven task manager. Add, view, and remove tasks within a session — all from the command line.

**Quick run:**
```bash
cd todo-list
python main.py
```

## 🚀 Getting Started

### Prerequisites

- **Python 3.6+** — [Download here](https://www.python.org/downloads/)
- No additional packages required — all projects use the Python standard library only.

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/EngYahia25/python-mini-projects.git

# 2. Navigate into the repository
cd python-mini-projects

# 3. Run any project
cd age-days-calculator
python main.py
```
