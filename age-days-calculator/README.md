# 🗓️ Age & Days Calculator

A lightweight Python command-line tool that calculates the approximate number of days you have been alive based on your age in years.

## Features

- 🔢 Converts age in years to days (using 365 days/year)
- ✅ Input validation — rejects negative numbers and non-integer values
- 📏 Formatted output with thousands separators for readability
- 🧩 Clean modular design following PEP 8 guidelines

## How to Run

```bash
python main.py
```

### Example Session

```
--- Age in Days Calculator ---
Enter your age in years: 25
You have lived for approximately 9,125 days.
```

## Requirements

- Python 3.6+
- No external dependencies
